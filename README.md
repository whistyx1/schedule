# Розклад УК-26-1

Зручний веброзклад для студентів групи **УК-26-1** Харківського національного університету радіоелектроніки.

Дані автоматично отримуються з офіційної системи CIST і перетворюються у формат, зручний для перегляду з телефона або комп’ютера.

## Можливості

- перегляд занять на день і тиждень;
- час, дисципліна, тип заняття, викладач та аудиторія;
- позначення поточного заняття;
- автоматичне формування `data/schedule.json` із CIST;
- адаптивний інтерфейс без фреймворків.

## Локальний запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r parser\requirements.txt
python parser\parser.py
python -m http.server 8000
```

Після цього відкрий [http://localhost:8000](http://localhost:8000).

> Джерело розкладу — CIST. Перед заняттями варто звіряти важливі зміни з офіційною системою університету.

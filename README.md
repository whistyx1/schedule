# Розклад УК-26-1

Зручний веброзклад для студентів групи **УК-26-1** Харківського національного університету радіоелектроніки.

Сайт показує розклад у зрозумілому форматі для телефона та комп’ютера. Дані автоматично отримуються з офіційної системи CIST.

## Можливості

- перегляд занять на день і тиждень;
- час, назва дисципліни, тип заняття, викладач та аудиторія;
- позначення поточного заняття;
- зручний адаптивний інтерфейс.

> Розклад може змінюватися. Перед важливими заняттями варто перевіряти інформацію в офіційній системі CIST.
